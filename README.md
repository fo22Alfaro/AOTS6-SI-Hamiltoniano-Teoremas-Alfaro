## Qué hay aquí (y qué no)

Este repo **no fabrica** p-valores experimentales ni declara resueltos P vs NP, Riemann o H₀.

Hace lo que el núcleo AOTS⁶ no tenía en forma auditable:

1. Diccionario en **unidades SI**.
2. **Protocolo** de tamaño muestral `n` y p-valor (pre-registro, no resultado fingido).
3. **Hamiltoniano modelo** `H_AOTS6` sobre `T^6`, con límite Schrödinger cuando el potencial periódico se anula.
4. **Reducción** de pretensiones ontológicas a enunciados matemáticos clasificados.
5. **Teoremas Alfaro** nombrados, con estatus: DEFINICIÓN / LEMA (probado) / CONJETURA (abierta).
